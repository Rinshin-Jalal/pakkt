## 📐 Typography

### **Font Family**

```
PRIMARY FONT: SF Pro (Apple's system font)
- SF Pro Display (for headers, large text)
- SF Pro Text (for body, readable text)  
- SF Pro Rounded (for labels, tags)

WHY SF PRO:
- Native to iOS (no custom fonts needed)
- Excellent readability
- Multiple weights available
- Optimized for screens
- Professional but modern
```

### **Type Scale**

```
DISPLAY (Headers, Titles)
Size: 32-48pt
Weight: Black (900)
Case: ALL CAPS or Title Case
Usage: Screen titles, card headers
Example: "PHONE JAIL"

HEADLINE (Subheaders)
Size: 24-32pt
Weight: Bold (700) or Heavy (800)
Case: Title Case or Sentence case
Usage: Section headers, emphasis
Example: "Mike missed gym!"

TITLE (Card titles)
Size: 20-24pt
Weight: Bold (700)
Case: Sentence case
Usage: Goal names, user names
Example: "Morning Gym"

BODY (Main content)
Size: 16-18pt
Weight: Regular (400) or Medium (500)
Case: Sentence case
Usage: Descriptions, comments
Example: "Check in before 7:30 AM"

LABEL (Small text)
Size: 13-15pt
Weight: Medium (500) or Semibold (600)
Case: UPPERCASE
Usage: Buttons, tags, metadata
Example: "2 HOURS AGO"

CAPTION (Tiny text)
Size: 11-13pt
Weight: Regular (400)
Case: Sentence case
Usage: Timestamps, fine print
Example: "Joined 3 weeks ago"
```

### **Typography Rules**

```
1. HEADERS ARE LOUD
   - Use Black weight (900)
   - ALL CAPS for maximum impact
   - Add 2px stroke/outline for extra emphasis
   - Never subtle

2. BODY IS READABLE
   - Never smaller than 16pt
   - Medium weight for easy reading
   - High contrast (white on black)
   - Generous line spacing (1.4-1.5)

3. LABELS ARE CLEAR
   - UPPERCASE for distinction
   - Bold enough to stand out
   - Short and punchy
   - Neon colored when important

4. HIERARCHY IS OBVIOUS
   - Size jumps are dramatic (not 18pt to 19pt)
   - Weight changes are clear (Regular to Bold, not Regular to Medium)
   - Color reinforces hierarchy (white primary, gray secondary)

5. SPACING IS GENEROUS
   - Letter spacing: +0.5px for UPPERCASE
   - Line height: 1.4-1.5 for body
   - Padding: Never cramped
```

## 🃏 Card Design System

### **Glass Cards (Primary)**

```
ANATOMY:
- Background: Semi-transparent dark (rgba(26, 26, 26, 0.8))
- Backdrop blur: 40-60px
- Border: 3px solid rgba(255, 255, 255, 0.2) or neon color
- Border radius: 16-20px
- Shadow: Soft, 0 8px 32px rgba(0, 0, 0, 0.5)
- Padding: 20-24px inside

VISUAL EFFECT:
- See-through but structured
- Depth through blur
- Light refracts through edges
- Floats above background

USAGE:
- Feed posts
- Goal cards
- Info panels
- Settings sections
```

### **Brutal Cards (Urgent/Important)**

```
ANATOMY:
- Background: Solid dark (#1A1A1A)
- No blur (sharp, defined)
- Border: 4px solid neon color (cyan/magenta/yellow)
- Border radius: 8-12px (less rounded, more sharp)
- Shadow: Hard offset shadow, 8px 8px 0px [neon color]
- Transform: Slight rotation (-2° to +2°)
- Padding: 20-24px inside

VISUAL EFFECT:
- In-your-face
- Aggressive
- Can't be ignored
- Pops off the screen

USAGE:
- Alert cards (missed goals)
- Fine activation
- Important actions
- Warnings
```

### **Hybrid Cards (Best of Both)**

```
ANATOMY:
- Background: Glass (blurred dark)
- Border: Thick neon (3-4px)
- Shadow: Both soft glow AND hard offset
  - Inner: 0 0 16px [neon color] (glow)
  - Outer: 4px 4px 0px [neon color] (brutal)
- Border radius: 16px
- Slight rotation: -1° to +1°

VISUAL EFFECT:
- Premium chaos
- Expensive but aggressive
- Glass meets neon
- This is THE signature look

USAGE:
- Check-in cards
- Jail cards
- Featured content
- Hero elements
```

## 🎭 Motion & Animation

### **Animation Principles**

```
1. SNAPPY, NOT SLOW
   - Duration: 0.2-0.4s max
   - Easing: ease-out or spring
   - No slow fades

2. AGGRESSIVE, NOT GENTLE
   - Overshoot on springs
   - Bounce effects
   - Shake on errors
   - Slam on entries

3. PURPOSEFUL, NOT DECORATIVE
   - Every animation has meaning
   - Success = confetti + scale up
   - Error = shake + red flash
   - Loading = pulse, not spin

4. PHYSICAL, NOT DIGITAL
   - Gravity effects
   - Momentum
   - Collision
   - Weight
```

### **Specific Animations**

**Button Press:**
```
1. User touches button
2. Scale down to 0.96 (instant)
3. Shadow reduces (3D squash)
4. Haptic feedback (light impact)
5. On release:
   - Scale back to 1.0 (spring)
   - Shadow returns
   - Haptic feedback (medium impact)
6. Duration: 0.15s down, 0.3s up
```

**Card Entry:**
```
1. Card starts off-screen (bottom)
2. Slides up with spring
3. Slight rotation settles
4. Shadow fades in
5. Duration: 0.4s total
6. Stagger: 0.05s between cards
```

**Success State:**
```
1. Action completes
2. Element scales up to 1.1
3. Toxic green glow pulses
4. Confetti bursts from center
5. Haptic: success notification
6. Scale back to 1.0
7. Duration: 0.6s total
```

**Error State:**
```
1. Error occurs
2. Element shakes (X-axis)
   - -10px → +10px → -8px → +8px → 0
3. Border flashes hot magenta
4. Haptic: error notification
5. Duration: 0.4s
```

**Loading State:**
```
1. Element pulses opacity
   - 1.0 → 0.6 → 1.0
2. Slight scale variation
   - 1.0 → 1.02 → 1.0
3. Loop continuously
4. Neon glow intensifies/fades
5. Duration: 2s loop
```

**Jail Timer:**
```
1. Numbers flip (odometer style)
2. Pulse every second
   - Scale: 1.0 → 1.05 → 1.0
3. Color shifts as time runs out:
   - >10 min: White
   - 5-10 min: Acid yellow
   - <5 min: Hot magenta
4. <1 min: Rapid pulsing (0.5s)
```

**Prison Bars (Jail Screen):**
```
1. Bars drift left-right slowly
   - -5px → +5px over 4s
2. Opacity flickers randomly
   - 0.1 → 0.2 → 0.15
3. Individual bars animate independently
4. Creates unsettling effect
```

☐ Are the borders thick? (3-4px minimum)
☐ Is the typography BOLD? (Black or Heavy weights)
☐ Does it have glass effects? (Blur, transparency)
